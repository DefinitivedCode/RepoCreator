## Native build and official images

The actual optimized Windows x64 application is built through the source-path
remapping wrapper:

```powershell
npm run desktop:build -- --ci --no-bundle --target x86_64-pc-windows-msvc
$env:REPO_CREATOR_SMOKE_EXE = (Resolve-Path 'src-tauri/target/x86_64-pc-windows-msvc/release/repo-creator.exe').Path
node tests/public-screenshots.mjs
```

The capture executable's Windows FileVersion and ProductVersion both report
**1.5.2**. Its SHA-256 is
`2a65c99b631ea7133b6575dbf7e81026f9725ff2fc3cb0d8a84f84018edec3d3`.
The native source-path privacy scan passes. A negative test against the previous
1.5.1 debug executable fails at the native version guard before writing any PNG.

Files, workspace, console, Settings and Readiness in both themes, plus detection

edited, composited, recoloured or mocked.
