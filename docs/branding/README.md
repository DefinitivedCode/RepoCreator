# Branding concepts for review

Open [the concept board](review.html) for three separate vector marks with 16px,
32px, monochrome and README banner previews.

**Recommendation: Module (A).** Its repeated open units connect repository
creation with the modular project workspace, and its geometry stays legible at
small sizes. Join (B) places more emphasis on creation; Assembly (C) has the
strongest solid silhouette but a more common addition symbol.
