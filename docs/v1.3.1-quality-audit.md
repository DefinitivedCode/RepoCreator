# v1.3.1 quality audit

The starting point was clean `main`, commit `0f960a5` (v1.3.0). Baseline TypeScript, 38 frontend tests and 52 Rust tests passed. The audit targeted the existing configuration hook, workspace panels, generation/preset defaults, prompt renderer, creation states, native window behavior and relevant tests. Existing generators, native operations and creation safeguards remain in place.

| Priority | Confirmed issue | Correction |
| --- | --- | --- |

| P2 | At 1100×740, a 56px header and 70px footer leave 614px. Simple Overview required 790px and Advanced 863px. | Paired independent fields, concise labels, compact grouping, contextual explanations and inline recent locations. Preserve normal overflow for expanded or enlarged content. |

| P2 | Handoff prompts included empty JSON briefs, and template/style changes discarded prompt edits. | Omit empty context, use readable labeled information, distinguish proposed/verified facts, and retain edits until explicit regeneration. |
| P2 | Large success file collections pushed essential metadata and actions below the fold. | Keep metadata/actions first; show file count with a collapsed preview and bounded tree/code scrolling; expose handoff through a clear disclosure. |
| P2 | Malformed/newer custom-template storage could be replaced while changing prompt settings. | Preserve unreadable data read-only and show a recovery notice. |
| P2 | Failed setup checks could leave a permanent checking message without recovery. | Show unavailable status and Recheck; startup loading errors offer retry. Ignore superseded environment responses. |

Display-scale emulation does not substitute for physical macOS launch or changing actual OS display settings.
