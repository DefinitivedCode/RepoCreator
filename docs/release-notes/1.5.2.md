# Repo Creator 1.5.2 — Technology Detection & Performance

Version 1.5.2 makes existing projects easier to configure and reduces waiting during everyday setup and workspace use.

### What's New

- **Evidence-based technology detection** — Review suggestions from local project files, choose what to add, and save your selections without running scripts or changing project files.
- **Faster setup and workspace opening** — Fewer repeated Git processes and independent setup checks running together reduce unnecessary waiting.
- **More reliable refreshes** — Outdated asynchronous results are ignored, the project library reloads when needed, and creation waits for refreshed prerequisites to pass.
- **Better Studio keyboard scrolling** — Expanded AI configuration stays reachable at supported window sizes while preserving the fixed footer.
- **More efficient desktop checks** — Windows browser and native verification run in parallel, with the same required checks and native coverage on all three platforms. Generated build files no longer stall the development browser's watcher.

### Installation

Download the Windows x64 or matching macOS package under **Assets** and compare its checksum with `SHA256SUMS.txt`.

Updater-enabled installed copies can receive this Beta through **Settings → Updates → Beta** after publication. Users of v1.4.0 and earlier must upgrade manually. Windows portable ZIP copies require manual replacement; extract the entire archive before opening the app. On macOS, move the application out of the DMG before using updates.

**Known limitations:**

- Windows installers remain unsigned at the operating-system level. Cryptographic updater signatures do not provide operating-system code signing.
- macOS builds are ad-hoc signed and not notarized; packaged installation and launch on physical Macs remain unverified.
- Windows installer installation/upgrades and in-app update/restart on both platforms remain unverified.
- Technology detection is bounded; very large or deeply nested projects may need manual technology additions. Readiness does not verify nested projects, Python environments or Shell-mode commands.
