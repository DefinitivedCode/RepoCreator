# Repo Creator 1.5.1 — Commands & Workspace Polish

Version 1.5.1 makes project command output clearer and brings more consistency to everyday setup screens.

### What's New

- **Readable command output** — Common ANSI colours and text styles render correctly, including output received in fragments.
- **Clickable web addresses** — Open HTTP and HTTPS links, including local preview servers, in your external browser when you choose them.
- **Suggested commands** — See available commands from project files, review the ones you want and save them without running anything automatically.
- **Console polish** — Clearer run status and alignment, preserved long lines, and scrolling that follows new output only while you are near the bottom.
- **Consistent setup screens** — One New Project status bar with a green Git-ready indicator, better Settings alignment, and refreshed screenshots from the actual 1.5.1 application.

### Installation

Download the Windows x64 or matching macOS package under **Assets** and compare its checksum with `SHA256SUMS.txt`.

Updater-enabled installed copies can receive this Beta through **Settings → Updates → Beta** after publication. Users of v1.4.0 and earlier must upgrade manually. Windows portable ZIP copies require manual replacement; extract the entire archive before opening the app. On macOS, move the application out of the DMG before using updates.

**Known limitations:**

- Windows installers remain unsigned at the operating-system level. Cryptographic updater signatures do not provide operating-system code signing.
- macOS builds are ad-hoc signed and not notarized; packaged installation and launch on physical Macs remain unverified.
- Windows installer installation/upgrades and in-app update/restart on both platforms remain unverified.
